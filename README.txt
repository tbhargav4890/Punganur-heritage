Punganur Heritage - phone-first PWA
1. Upload this folder to any HTTPS static hosting service.
2. Open the site in Chrome on Android.
3. Chrome menu > Add to Home screen / Install app.
4. Use the app; cattle, breeding and lactation records are stored locally on the phone.
5. Use Home > Export Backup regularly.

For a true installable APK and cloud sync, this PWA can later be packaged/extended.
